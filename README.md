## 🚀 Getting Started

### Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/vastunex-infra.git
   ```
2. Open `index.html` in your browser — that's it!

### Deploy on GitHub Pages

1. Go to your repository **Settings**
2. Navigate to **Pages** → **Source**
3. Select `main` branch and `/ (root)`
4. Click **Save** — your site will be live at:
   ```
   https://your-username.github.io/vastunex-infra/
   ```

### Deploy on Netlify (Free)

1. Go to [netlify.com](https://netlify.com) and sign up
2. Drag and drop the project folder onto the Netlify dashboard
3. Your site goes live instantly with a free URL

## ✏️ Customization

All content is in `index.html`. To edit:

| What to change | Where to find it |
|---|---|
| Phone numbers | Search `9369164030` in the file |
| Company name / tagline | Hero section & navbar |
| Service descriptions | `.service-card` blocks |
| Colors | `:root` CSS variables at the top |
| WhatsApp number | `wa.me/91XXXXXXXXXX` in the `<a>` tag |
| Address / location | About & Contact sections |

### Color Palette

```css
--navy:  #1a2342   /* Primary dark blue */
--green: #2daa4f   /* Accent green */
--yellow:#f5c518   /* Highlight yellow */
--red:   #e63030   /* Banner red */
```
