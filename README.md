# 🏗️ Vastunex Infra — Official Website

> **Building Dreams** | All Real Estate Solution Under One Roof

A modern, responsive single-page website for **Vastunex Infra**, a construction and real estate company based in Kanpur, Uttar Pradesh. Built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies.

---

## ✨ Features

- ✅ **Fully Responsive** — works on mobile, tablet, and desktop
- ✅ **Single HTML File** — no build tools, no npm, just open in browser
- ✅ **Smooth Scroll Navigation** — fixed navbar with anchor links
- ✅ **Animated Hero Section** — fade-up entrance animations
- ✅ **WhatsApp Floating Button** — direct chat link with pulse animation
- ✅ **Contact / Enquiry Form** — service selector + requirements field
- ✅ **Phone Bar** — all 3 contact numbers prominently displayed
- ✅ **Google Fonts** — Oswald + Barlow for professional typography
- ✅ **No JavaScript frameworks** — lightweight and fast
